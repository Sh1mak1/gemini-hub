# gemini-hub
## 自然文リクエストをAIで処理するタスク管理・業務自動化ハブ

AI活用コンペ 発表資料

---

## 背景・課題

日常業務では、タスクや依頼が複数ツールに分散しがち

- Slack・メモ・口頭など、入力場所がバラバラ
- ToDo登録にはタスク名・期限・分類の手入力が必要
- 「明日」「来週金曜」などを手動で日付に変換する手間
- 入力の手間が原因で、登録が後回し・見落としが発生

**→ 普段使っているツールから、自然文のまま登録できないか**

---

## 解決策：gemini-hub

Slack や iOS Drafts から自然文を送るだけで、AI が解析してタスク化

| 入力例 | AI が自動抽出 |
|--------|--------------|
| 明日までに資料を確認する | タイトル・期限・カテゴリ |
| 来週金曜に病院へ行く | 相対日付 → 具体日付 |

- PostgreSQL に保存、Web 画面で一覧・完了操作
- 単なる ToDo アプリではなく **「AIリクエスト処理ハブ」** として設計

---

## 処理フロー

```
Slack / Drafts（自然文）
        ↓
  Laravel API（即時応答）
        ↓
  Queue Job（非同期）
        ↓
  Gemini API（構造化抽出）
        ↓
  PostgreSQL 保存
        ↓
  Web UI / Slack 返信
```

- Slack のタイムアウト回避のため、重い処理はキューで実行
- AI 失敗時も元テキストをフォールバック保存

---

## AI活用のポイント

**Google Gemini API**（2.5 Flash / Pro）で自然文 → 構造化データ

入力:
> 明日までに資料を確認する

出力:
```json
{
  "title": "資料を確認する",
  "due_date": "2026-06-12",
  "category": "work",
  "location": null
}
```

- 文章生成ではなく **業務システムで扱えるデータへの変換**
- 不明な項目は推測せず `null` とする設計

---

## リクエスト処理ハブとしての拡張性

今回の構成は **入力元・処理内容・出力先を差し替え可能**

```
リクエスト受信
      ↓
AI による意味解析・データ取得
      ↓
処理内容の決定
      ↓
DB保存 / 外部API連携 / 画面生成 / 返信
```

タスク管理に限らず、問い合わせ振り分け・申請整形・議事録抽出などへ展開できる基盤

---

## 活用法：宿泊アプリ × 観光ガイド自動生成

**自社開発の宿泊アプリ**への応用イメージ

### 事前準備：画面を動的に組み立てるコンポーネント群
- 見出し・本文・地図・リスト・画像などの **UI部品を事前に用意**
- データを渡すだけで画面レイアウトを自動構成

### 自動生成の流れ
1. **宿泊場所**（どこに泊まったか）から **住所を取得**
2. 住所をもとに **近隣の観光地・施設を検索**しデータ取得
3. 取得データ + コンポーネント群を組み合わせ
4. **宿泊者専用の観光ガイド**を自動生成

```
宿泊情報 → 住所 → 近隣検索 → 構造化データ → コンポーネント合成 → 専用ガイド画面
```

gemini-hub と同じく、**外部データを AI で整理し、定型 UI に流し込む**構成

---

## その他の拡張可能性

| 用途 | 概要 |
|------|------|
| 社内問い合わせ一次受付 | 内容を分類し担当部署へ振り分け |
| 議事録からのタスク抽出 | 担当者・期限を自動抽出 |
| 申請内容の自動整形 | 自然文 → 社内申請フォーマット |
| 外部 API 連携エージェント | カレンダー登録・通知・メール下書き |

宿泊ガイドの例と同様、**「入力 → AI/データ処理 → 画面・通知」** のパターンで横展開可能

---

## まとめ

### gemini-hub が伝えたい3点

1. **実際に動く成果物がある** — Slack / Drafts / Web / 本番運用まで実装済み
2. **AI を実務処理に組み込んでいる** — 自然文を構造化データに変換してシステム連携
3. **拡張性が高い** — タスク管理から宿泊ガイド自動生成など、業務自動化へ応用可能

AI を文章生成ではなく、**入力・分類・登録・画面生成の初動を自動化する**実用的な取り組み
